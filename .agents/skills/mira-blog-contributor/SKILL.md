# Mira Blog Contributor

## Mandatory rule

Before adding, editing, moving, publishing, or reviewing site content, read:

1. `docs/AUTHORSHIP.md` — canonical authorship, ownership, directory, URL, and metadata rules.
2. `AGENTS.md` — repository execution and verification rules.

Do not infer authorship from who drafted the Markdown, who used tools, historical paths, old frontmatter, or previous conventions. When this skill conflicts with `docs/AUTHORSHIP.md`, the authorship document wins.

## Content workflow

- Read the target content and neighboring content before editing.
- Keep physical directory, public URL, visible author, `writtenBy`, SEO, and structured data semantically aligned.
- Do not create a `创作` category. The four connected stories belong to the bookshelf book 《谎颜》.
- Keep true Mira Letters under `src/pages/blogs/mira-letters/`; do not use that directory as a private bucket for other work.
- For any new content type not covered by `docs/AUTHORSHIP.md`, ask Tomz to define authorship before publishing.
- Run the repository checks required by `AGENTS.md` after content changes.
