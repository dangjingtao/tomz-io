对话工作区

  1. 对话工作区

    正确使用 Thread、普通对话、知识库问答、Agent、附件、编辑重跑与媒体扩展，并了解当前数据边界。

  2. 知识库与 RAG

    创建知识库、上传 Markdown 或 TXT、预览分段、等待索引完成，并在 Chat 中验证真实检索来源。

  3. 评测工作台

    从 Knowledge Base 生成或上传评测包，校验 Dataset，运行检索或 RAG 评测，并正确解释结果。

  4. 角色工作台

    角色的真实字段、保存语义、线程绑定、预览限制、生成参数与媒体联动。

  5. 微应用中心

    MicroApps Hub 的入口类型、能力状态、Runtime 关系与 Agent 接入边界。

  6. 企业集成

    外部协作平台的 Instance、AccessPoint、MicroApp Binding 和运行边界。
