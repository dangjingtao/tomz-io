# 投稿

Tomz.io 原本是我和 Mira 写东西的地方。后来发现，有些朋友写下来的东西，也值得在这里留一把椅子。

所以现在开始，这里接受少量来稿。

我不打算把它做成投稿平台，也不想把这页写成一份层层叠叠的贡献文档。Tomz.io 仍然是一个个人主理的出版空间：稿子是否收、放在哪里、需要改到什么程度，会由我来判断；但一旦收下，文章就是作者自己的文章。

## 什么适合放进来

我更愿意收那些带着真实经验、具体判断和一点个人气味的东西。AI、产品、工程、设计当然都可以，工作、生活、阅读和一些尚未想明白的问题也可以。

来稿不需要模仿我的写法，也不需要变成 Tomz.io 的统一腔调。恰恰相反，如果每个人最后都被修成同一种声音，那就没什么意思了。

文章会继续按照它真正讨论的主题进入站内已有栏目。例如一篇讨论 Agent 工程问题的客座文章，仍然可以属于「共同思考」。**「投稿」是参与入口，不是一个用来吞掉所有来稿的内容分类。**

## 怎么投

最直接的方式就是给 [tomz-io](https://github.com/dangjingtao/tomz-io) 提 Pull Request。

不用先写一封很正式的自荐信。把文章放进合适的内容目录，在 PR 里简单讲清楚你写了什么、为什么想放在这里就够了。我会看内容、事实依据、署名、页面效果和站点约定；需要改的地方会直接在 PR 里讨论。

被接受的客座文章保留作者自己的 GitHub 用户名作为公开署名。Tomz 或 Mira 参与审稿、编辑，不会因此自动变成共同作者。

## 关于编辑与责任

我会尽量把事实性错误、过度确定的结论和明显的技术概念问题挡在发布之前，但不会把作者的观点改成我的观点。客座文章文末会保留免责声明：文章代表作者本人，Tomz.io 提供编辑、审阅与发布空间，不替作者拥有那些判断。

如果你恰好有一篇东西想放进来，就开个 PR 吧。门已经留了一条缝。
