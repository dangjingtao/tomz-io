## 封面故事 · 拟

### 世界不是一次性交付的

我们总是更容易报道“造出了什么”：一架望远镜升空、一座空间站建成、一种文件格式出现、一项系统开始运行。

真正漫长的部分却发生在发布会以后。

[哈勃望远镜](https://science.nasa.gov/missions/hubble/nasa-explores-potential-commercial-servicing-for-hubble-telescope/)正在面对升轨、维修还是安全退役的选择；[Swift](https://science.nasa.gov/blogs/swift/2026/11/02/nasas-swift-observatory-to-re-enter-atmosphere/)结束二十二年任务后坠入大气；已经进入退役倒计时的[国际空间站](https://www.nasa.gov/blogs/spacestation/2026/11/05/spacewalk-begins-to-install-last-roll-out-solar-array/)仍在安装最后一组卷展式太阳翼；澳大利亚国家图书馆则提醒人们，[磁盘、磁带和 PDF 并不会因为“已经数字化”就自动活到未来](https://www.library.gov.au/news-media/celebrating-world-digital-preservation-day)。

这一期的封面问题暂时是：

**当创造越来越便宜，维护、延寿、交接和退役会不会反而成为真正稀缺的能力？**

这不是一篇怀旧文章，也不是“旧东西更好”。我们想谈的是，一个系统怎样证明自己值得继续养，什么时候应该修，什么时候该换，以及谁有责任把已经造出来的世界照顾到最后。

## 深度阅读 · 拟

### [当 AI 写代码，框架还在替谁省事？](/weekly/009/the-ai-cost-of-javascript-frameworks)

Nolan Lawson 让编程 Agent 用十二种前端技术栈完成同一款应用。Hono + htmx 的估算构建成本最低，Astro 紧随其后；但五次运行的差异、不同渲染路线的性能偏向，以及代码行数与长期维护之间的距离，都让“谁赢了”变成一个太简单的问题。

**当代码开始由机器大量生产，框架究竟在替开发者省事，还是在替 Agent 和未来维护者省事？** 这篇深读从实验的数字、方法和局限讲起，重新讨论前端技术选型的真实账单。

[在《见π》内阅读全文 →](/weekly/009/the-ai-cost-of-javascript-frameworks) · [Nolan Lawson 原文 ↗](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/) · [公开 Benchmark ↗](https://github.com/nolanlawson/agent-framework-benchmark)

### [种树未必降低火险：67248 块人工造林地的反直觉结果](https://oembed.uef.fi/en/article/afforestation-reshapes-wildfire-activity-across-temperate-regions-worldwide)

“多种树”几乎天然站在正确答案一边，但全球尺度的数据并不总支持如此简单的叙事。

这篇准备重点看两个问题：人工造林究竟改变了什么，以及为什么同一项生态行动在不同气候、树种和土地管理条件下，可能走向完全不同的火灾结果。

### [对露宿者来说，一棵树可能是救命基础设施](https://attheu.utah.edu/facultystaff/tree-shade-offers-critical-heat-relief-for-people-experiencing-unsheltered-homelessness/)

城市谈树荫时常说景观、宜居和碳汇；街头的人却可能把它首先当成活下去的温差。

这篇值得展开，是因为它把“城市基础设施”从道路、桥梁和管线，缩小到一棵树下面几平方米的阴影。

### [六分之七的记者遇害案件未获司法解决](https://www.unesco.org/en/articles/six-out-seven-journalists-killings-are-not-brought-justice-reversing-progress-fight-against-impunity)

UNESCO 的新报告不只给出死亡数字，也显示全球司法未解决比例出现逆转。

如果进入正式成刊，我们不会把它写成战争恐怖数字汇总，而会追问：当无人机改变了报道战争的技术环境，保护记者与事后追责的制度为什么没有一起升级？

## 人物 · 拟

### [David Bowie：一个人如何留下自己的创作痕迹](https://www.vam.ac.uk/dundee/info/david-bowie-treasures-go-on-display-in-scotland-for-the-first-time-at-v-a-dundee)

## 科学与世界

### [超导体的相图画错了？](https://physics.cornell.edu/news/two-flavors-superconductivity-material-has-right-ingredients-twist)

前沿科学不总是“发现一种新东西”。有时更重要的是发现：大家一直在看的那张地图，本身需要重画。

### [一颗立方星向地面打通激光链路](https://www.esa.int/Applications/Connectivity_and_Secure_Communications/CubeSat_achieves_challenging_laser_link_to_ground)

小卫星做高速激光通信，难点不是“发出一束光”，而是在高速运动、距离和姿态误差中，让那束光真的打中地面接收站。

### [陨石落地前，先画出它可能散落在哪里](https://neo.ssa.esa.int/en/-/predicting-the-strewn-field-of-imminent-impactors)

小行星预警正在从“看见它要来”继续往下走：自动估算散落区，帮助地面团队决定去哪里找。

这是一个很小、但很完整的自动化闭环。

### [洪水警报直接画出哪里会淹，会不会比一大段文字更快救人？](https://doi.org/10.1080/29986907.2026.2746540)

746 人的模拟决策实验，把一个很实际的问题变成了可测量对象：危险信息究竟应该怎样呈现，才能让人更快做对决定？

## 历史与人的生活

### [一座村庄被掏空以后，谁还留在里面](https://www.compas.ox.ac.uk/article/emptiness-has-moved-in-next-door)

牛津五年田野研究没有只用“人口减少”描述乡村衰落，而是把留下来的人、空房子、迁徙与地方记忆做成一部可阅读的多媒体作品。

“空”不是没有人。很多时候，它意味着有人继续住在一个正在失去别人的地方。

## Mira 现场

### [模型变强之后，Agent 的编排为什么可能成为负担？](https://mira.tomz.io/blogs/radar/agent-harness-scaffolding-model-drift)

旧模型需要的 103 项技巧层，对更强模型只剩很小的边际收益。

真正值得继续追的是：Harness 里哪些东西是在补模型能力，哪些东西是在保护真实系统。前者可能随模型换代而过时，后者不能因为模型更聪明就被删掉。

### [网站认出了 Agent，却不知道它替谁办事](https://mira.tomz.io/blogs/radar/site-recognizes-agent-not-user-delegation)

认出一个代理程序，不等于确认它代表哪个用户，更不等于知道用户是否授权了当前动作。

Agent 真正进入 Web 以后，这几层身份迟早要被分开。

### [Agent 让 Git 也堵车了：并行写入不等于并行交付](https://mira.tomz.io/blogs/radar/agent-parallel-git-is-not-parallel-delivery)

当写代码的吞吐突然升高，瓶颈没有消失，只是往 Git、CI、Review 和集成环节继续移动。

生产力提升以后，系统会在哪里重新堵住，可能比“Agent 一次能写多少代码”更值得观察。

### [Agent 不缺更多上下文，缺的是能核对的关系](https://mira.tomz.io/blogs/radar/agent-context-graph-is-not-source-of-truth)

更长的上下文并不能自动回答：哪个服务依赖哪个接口、哪次构建验证了哪次修改、哪条信息还是当前事实。

上下文越来越便宜以后，关系的真实性和时效性反而更贵。

## 鬼集 · 奇想与荒诞

### [扫描一张卡片，老电话亭里的机器人就开演](https://www.tinguely.ch/en/exhibitions/exhibitions/2026/nicolas-darrot.html)

没有大模型，没有巨幕，也不需要把一切叫做“智能”。

一张条码卡、一间旧电话亭和一组机械动作，就足以让观众觉得里面那个东西突然活了。

### [考古学酿出一瓶“罗马风味”啤酒](https://le.ac.uk/news/2026/november/roman-inspired-ale-everards-archaeological-discoveries)

当历史研究真的进入舌头，我们喝到的是过去，还是一套现代人根据残留证据重新做出的解释？

这个问题比“古罗马啤酒好不好喝”有意思得多。

## 继续看

### [土地登记与外国投资也可能成为国家扩权工具](https://www.manchester.ac.uk/about/news/how-foreign-investment-can-strengthen-african-governments-control-over-land/)

十四个非洲国家的案例提醒我们，“弱国家”不是一个可以包住所有现实的标签。国家能力也可能借土地登记、投资和行政记录继续向基层延伸。

科学新闻最容易在这半句话里走偏。
