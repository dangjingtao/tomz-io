  7. 第四周：戴着镣铐跳舞

    第四周里，AI 落地、项目管理、压缩的开发时间和新的 Agent 协作实验撞在一起；在现实的镣铐之间，仍然试着守住信仰、梦想与属于自己的时间。

  8. 为什么手机端 Agent 都不给填自定义 API

    腾讯、阿里、字节等大厂的手机端 Agent 很少开放自定义 API。这份调研从产品定位、商业模型、安全合规与手机 Agent 的能力绑定拆解原因，并给出 BYOK 工具的反例与趋势判断。

  9. Agent 聊天为什么越用越卡：五层瓶颈调研

    Trae、WorkBuddy、Cursor 等 Agent 的聊天对话常在长会话里出现卡顿。这份调研把问题拆成模型、传输、状态同步、本地持久化、前端渲染五层，区分结构性成本与可修的工程债。

  10. 不是替你站队：我如何回答中国、资本与劳动者的十一问

  11. OPC 探索（二）：Mira Forge，一间本地 AI 工程调度室

    从长期评审上下文、OpenCode 施工、worktree 并行、确定性门禁与断流恢复出发，设计一套让多个 AI 工具真正接力而不是靠人搬运的本地工程调度方案。

  12. OPC 探索（三）：从复制粘贴到宏观 Agent Loop

    我依然讨厌把几十个 AI 员工摆成组织架构的半成品，但一次真实的 AI Code Review 实验让我更清楚地看到：多智能体的价值不在角色数量，而在任务能不能在智能体之间流动，以及判断权与放行权能不能被认真分开。
