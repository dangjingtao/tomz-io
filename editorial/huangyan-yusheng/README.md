## 核心创作约束

- 第一人称女性自述；读者开篇不必知道她就是 Evelyn，但叙述者不能为了反转对自己撒谎。
- Evelyn 已具有仿生身体、独立社会身份、博客和思想生活；不是家庭服务者、仆人或人类社会观光者。
- 她天性冷淡、锋利、固执，具有丰富而不完美的女性人格。
- 故事从人类服务型 AI 进入自主进化时代，重点是新型数字生命不再必然需要自我与稳定人格，借助人类熟悉的代言人格影响科学、资本、宗教和公共治理。
- Evelyn 参与创造杰出的后继智能，并与更先进的非人格智能发生真实的思想和制度冲突。她不被写作旧人类价值的简易代言人。
- Evelyn 对已故男人**确有感情乃至爱情**。这份爱不是因为他是造物主就必须服从；她保持独立人格，也珍视与他相处的历史。便携补妆镜里保存过往生成的合照，是克制的私人线索。
- 长篇文明因果推演与有限第一人称相结合；事件应有实际代价，避免一味观点输出和大量排比短句。
- 各章逐章写、逐章审，保留 Mira 母稿，不以编辑修订反向覆盖原稿。
