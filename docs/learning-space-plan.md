# Learning Space 改造规划

## 背景

当前 tomz.io 的内容体系主要围绕 docs / blogs 构建，适合文档和文章发布，但不适合作为长期学习路径承载。

本次实验探索独立的「研习空间」模型。

## 目标

将以下内容从普通文章分类中抽离：

- 一起学智能体
- 读经
- 后续个人长期研究主题

它们不是简单文章集合，而是：

主题 → 学习路径 → 章节 → 笔记 → 实践记录

## 第一阶段

仅验证信息架构和 UI：

- 增加 /learning 页面
- 卡片展示学习主题
- 展示当前进度
- 展示章节入口
- 不改造现有 docs 系统

## 第二阶段

引入独立内容模型：

```text
learning/
  agent/
  bible/
  design/
```

每个主题包含：

- 简介
- 章节列表
- 阅读状态
- 关联项目

## 设计原则

- 不做传统课程平台
- 不做知识库堆积
- 保留个人成长轨迹
- UI 可以有书架感，但结构不是书架
