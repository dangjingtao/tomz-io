参与 Tomz.io

投稿是内容进入 Tomz.io 的一种方式，而不是独立内容栏目。已发布来稿回到博客等对应内容体系，并保留真实署名与贡献关系。

Tomz Dang3 分钟阅读站务发布于 2026年8月31日更新于 2026年9月10日 16:39

Tomz.io 原本是我和 Mira 写东西的地方。后来发现，有些朋友写下来的东西，也值得在这里留一把椅子。

所以这里接受少量来稿。但我不想再把「投稿」做成另一个内容栏目。

投稿是一种进入方式#

一篇文章因为是外部作者写的，不应该就被关进另一套目录里。发布以后，它应该回到自己真正属于的地方：博客文章进入博客；以后如果有人参与见π或其它内容，也按对应内容产品的规则出现。

这页只负责三件事：怎么参与、谁参与过、署名与编辑关系怎么算。

作者是谁，按真实作者记录；Tomz 或 Mira 参与审稿、编辑，不会因此自动成为共同作者。内容放在哪里，则由内容本身决定。

客座作者#

已经在 Tomz.io 发表过内容的外部作者，统一放在 客座作者 页面介绍。这里不再逐个展开作者和文章。

什么适合放进来#

我更愿意收那些带着真实经验、具体判断和一点个人气味的东西。AI、产品、工程、设计当然都可以，工作、生活、阅读和一些尚未想明白的问题也可以。

来稿不需要模仿我的写法，也不需要变成 Tomz.io 的统一腔调。如果每个人最后都被修成同一种声音，那反而没什么意思。

怎么投#

最直接的方式仍然是给 tomz-io 提 Pull Request。

不用先写一封很正式的自荐信。在 PR 里讲清楚你写了什么、为什么想放在这里就够了。文章最终放进哪个内容目录，会在编辑阶段一起确定；博客类客座文章统一进入 src/pages/blogs/guest-contributions/。

我会看内容、事实依据、署名、页面效果和站点约定；需要改的地方直接在 PR 里讨论。

编辑与责任#

我会尽量把事实性错误、过度确定的结论和明显的技术概念问题挡在发布之前，但不会把作者的观点改成我的观点。

客座文章保留作者自己的公开署名与责任边界。Tomz.io 提供编辑、审阅与发布空间，不替作者拥有那些判断。

如果你恰好有一篇东西想放进来，就开个 PR 吧。门还是留着的，只是不再另盖一间屋子。
